# Spendprint

뱅크샐러드에서 내보낸 엑셀을 올리면 내 지출을 정리해 보여주는, 내 PC에서만 도는 사이트입니다.

지금은 1단계입니다. 파일을 올려 원장에 합치고, 전체 내역을 확인하고, 가져오기를 되돌릴 수 있습니다. 분류 보정, 분석 화면, 고정비, AI 연결은 다음 단계에서 만듭니다. 설계는 `docs/superpowers/specs/`에 있습니다.

## 실행

`Spendprint.cmd`를 두 번 누르면 됩니다. 처음에는 필요한 것을 설치하고 화면을 빌드하느라 시간이 조금 걸립니다. 준비가 끝나면 브라우저가 `http://127.0.0.1:4780`으로 열립니다. 끄려면 검은 창에서 Ctrl+C를 누릅니다.

직접 실행하려면:

```
npm install
npm run build
npm start
```

## 내역 올리기

1. 뱅크샐러드 앱의 가계부 설정에서 '파일로 받기'를 누릅니다.
2. 메일로 온 엑셀 파일을 PC에 저장합니다.
3. Spendprint 화면 아무 곳에나 파일을 끌어다 놓습니다.

적용하기 전에 무엇이 추가되고, 바뀌고, 사라지는지 먼저 보여줍니다. 파일은 올리는 주기나 순서와 상관없이 맞게 합쳐집니다. 겹치는 기간은 새 파일 기준으로 바뀌고, 그보다 오래된 기록은 그대로 남습니다.

## 데이터가 있는 곳

- 모든 데이터는 `data/` 폴더에 있고 git에 올라가지 않습니다. 다른 폴더를 쓰려면 환경변수 `SPENDPRINT_DATA_DIR`을 지정합니다.
- `data/spendprint.db`: 데이터베이스
- `data/imports/`: 올린 원본 파일의 사본
- `data/backups/`: 가져오기나 되돌리기 직전의 데이터베이스 백업(최근 20개)
- 서버는 `127.0.0.1`에만 열리고, 화면은 바깥에서 아무것도 불러오지 않습니다.

## 도구

| 명령 | 하는 일 |
|---|---|
| `npm run sample` | `data/sample/`에 가짜 내보내기 파일 두 개를 만듭니다. 실제 데이터 없이 눌러 볼 때 씁니다 |
| `npm run diagnose -- <파일>` | 엑셀 파일의 구조만 출력합니다(값은 출력하지 않음). 뱅크샐러드가 형식을 바꿔 가져오기가 실패할 때 씁니다 |
| `npm run check:offline` | 빌드한 화면이 바깥 자원을 불러오지 않는지 확인합니다 |
| `npm test` | 테스트 |
| `npm run typecheck` | 타입 검사 |

실제 파일이 끝까지 읽히는지 확인하려면(건수만 비교하고 값은 출력하지 않습니다):

```powershell
$env:SPENDPRINT_REAL_FILE = 'C:\경로\2025-11-23~2026-11-23.xlsx'; npx vitest run test/real
```

## 개발

```
npm run dev:server   # API 서버 (4780)
npm run dev          # 화면 개발 서버
```
